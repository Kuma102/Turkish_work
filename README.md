# Оценка стоимости недвижимости в Турции

Проект по машинной обучению для прогнозирования стоимости объектов недвижимости в Турции. Модель выполняет оценку стоимости как для сделок купли-продажи, так и для долгосрочной аренды на основе параметров объекта (площадь, этажность, возраст здания, тип отопления, локация).

Репозиторий проекта: https://github.com/Kuma102/Turkish_work/tree/main

## Разделы и этапы работы

1. Разведочный анализ данных (EDA): Исследование распределения цен по регионам, анализ взаимосвязей между параметрами жилья и итоговой стоимостью, выявление аномальных значений.
2. Подготовка и очистка данных: Обработка пропущенных значений, фильтрация выбросов по ключевым характеристикам, приведение цен из различных валют к турецкой лире (TRY).
3. Эксперименты с моделями: Сравнительный анализ алгоритмов регрессии (Linear Regression, Random Forest, CatBoost). Алгоритм CatBoost показал наилучшее качество на валидации.
4. Разработка сервиса: Сборка веб-приложения на базе FastAPI и Streamlit для взаимодействия с обученными моделями.

## Ключевые решения архитектуры

* Разделение по типам сделок: Реализованы две отдельные модели CatBoostRegressor (одна для продажи, вторая для аренды) ввиду разной природы ценообразования.
* Работа с категориальными признаками: Категории передаются напрямую в CatBoost через внутренний механизм `cat_features`, что избавляет от необходимости использовать One-Hot Encoding.
* Логарифмирование целевой переменной: Обучение выполняется на логарифмированных значениях цен (`np.log1p`) для снижения влияния выбросов, с последующим обратным преобразованием (`np.expm1`).

## Структура репозитория

### Аналитические ноутбуки
* `Первая работа.ipynb` — Основной ноутбук с полной цепочкой обработки: исследовательский анализ, очистка данных, сравнение моделей и финальное обучение.
* `Тестирование модели.ipynb` — Ноутбук для проверки работы готовой модели на контрольной выборке и расчета метрик качества.

### Модуль приложения (папка `PythonProject1`)
Содержит рабочий код сервиса и все сопутствующие артефакты:
* `main.py` — Backend-сервис на FastAPI, принимающий входящие запросы и выполняющий предсказание.
* `app.py` — Пользовательский интерфейс на Streamlit.
* `model.pkl` / `catboost_model.pkl` — Сохраненные веса обученных моделей.
* `scaler.pkl` / `model_columns.pkl` — Артефакты предобработки и структура признаков.
* `test_real_estate_samples.csv` — Набор данных для проверки работы инференса.
* `result_real_estate_samples.csv` — Выходной файл с результатами прогноза (`predicted_price`).
* `requirements.txt` — Список зависимостей проекта.

## Метрики и результаты

Оценка проводилась на тестовом наборе данных с конвертацией значений обратно в TRY:

* Сегмент продажи (CatBoost): Коэффициент детерминации $R^2 = 0.68$. Модель корректно описывает основные ценообразующие факторы на широком диапазоне цен.
* Сегмент аренды (CatBoost): Средняя абсолютная ошибка MAE = 3367 TRY. Положительное значение $R^2 = 0.09$ подтверждает способность алгоритма улавливать общие тренды рынка аренды при высокой естественной вариативности цен.

## Порядок запуска

1. Клонирование репозитория:
   git clone https://github.com/Kuma102/Turkish_work.git
   cd Turkish_work

2. Переход в директорию приложения и установка зависимостей:
   cd PythonProject1
   pip install -r requirements.txt

3. Запуск Backend (FastAPI):
   uvicorn main:app --reload

4. Запуск Frontend (Streamlit) в отдельном терминале:
   streamlit run app.py
